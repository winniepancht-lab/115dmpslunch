# 東門國小家長會・營養午餐試菜系統 v3

三種角色、三個入口：

| 角色 | 入口 | 能做什麼 |
|---|---|---|
| 一般家長（公開） | `index.html`、`week.html` | 只看去識別化內容：年級代表、照片、已核可的紀錄與議題 |
| 輪值家代 | `rep.html?t=個人連結` | 只能填「自己輪值日」的試菜心得與照片，送出後待幹部審核；沒有議題／意見欄位 |
| 幹部 | `admin.html`（通關密語） | 審核、補登、議題、班表、統計、查詢比對 |

## 一、為什麼更安全
- 試算表**不再發布到網路**，前台改讀 Apps Script 的「公開資料」介面，那裡只輸出已上線資料的年級、文字、照片，**沒有姓名、班級、填報時間**。
- 家代以個人連結（32 碼隨機 token）填寫，伺服器會檢查「這位家代今天是否輪值」；沒有班表就不能送出。
- 幹部操作都要通關密語；任何人無法直接編輯或下載後台資料。
- 家代送出 → 待審 → 幹部核可才公開。幹部補登可「一次上線」。

## 二、設定步驟（依序做，一次）
1. **停止舊的公開**：試算表 → 檔案 → 共用 → 發布到網路 → **停止發布**（v2 的 CSV 連結會失效，這是預期的）。確認試算表一般存取權是「限制」。
2. **Apps Script**：把 `Google_Apps_Script.js` 全部貼上取代 → 儲存 → 部署 → 管理部署作業 → 鉛筆 → 版本「新版本」→ 部署。網址與 `KEY` 都不變，`js/config.js` 不用改。
   首次若要求授權請同意。新分頁（紀錄、議題、班表、家代名冊、菜單）會自動建立。
3. **上傳網站**：整個資料夾覆蓋上傳 GitHub Pages。
4. **登入後台** `你的網站/admin.html`：
   - 「班表與設定」→ **匯入 v2 舊資料**（把 9 月起的紀錄與議題搬進 v3）。
   - 「班表與設定」→ 選輪值表與名冊 xlsx → **解析並匯入**（姓名只存在私有試算表）。
   - 在「家代個人填寫連結」逐位按「複製邀請訊息」，用 LINE 傳給該位家代。
5. 自己用一個家代連結試填一筆，到後台核可，再開前台確認。

## 三、每天怎麼用
- **家代**：輪值當天開自己的連結 → 貼心得、選照片 → 送出。輪值後 2 天內可補填；被退回會顯示原因，修改後再送出。
- **幹部**：開後台「待審核」→ 檢查文字與照片（可改字、移除照片）→ 核可，或「全部核可上線」。
- **補登**：「補登」可單筆；也可貼 LINE 文字批次補登，系統依班表自動對應家代，確認後一次上線。
- **議題**：在「議題」新增／回覆／結案，可附照片；回覆留空 = 追蹤中。
- **統計與比對**：「家代統計」看每位試菜次數與日期、缺填、還沒試菜；「每日輪值對照」逐日看誰填了；可匯出 CSV。
- **下架／刪除**：「紀錄查詢」找到該筆 → 下架（可再上線）或刪除（照片丟垃圾桶）。

## 四、教育部平台菜單與菜色照片（v3.2）
系統向「教育部校園食材登錄平台」的公開查詢介面取得東門國小每日菜單與菜色照片，存起來後用在家代填寫頁、補登、前台。
- 貼上新版 Apps Script 後，**在編輯器函式選單選 `authorizeAll` 按「執行」一次**（授權連外網），再部署為「新版本」。
- 伺服器查不到時，會改由幹部／家代自己的瀏覽器向平台查詢（備援）。
- 前台會標示「資料來源：教育部校園食材登錄平台」；平台菜色照片只在那天沒有家代照片時顯示，並標示「非家代現場拍攝」。
- 後台「家代與設定」可手動同步、修改菜色、關閉某天的平台照片。手動填的菜色不會被覆蓋。
- 同步失敗時展開「技術細節」，把內容貼給開發者。

## 五、版本與更新
- 網頁與 Apps Script 版本要一致（目前 3.4）。不一致時後台上方會出現紅色警告。
- 更新網站檔案後若畫面沒變，是瀏覽器快取：3.2 起檔案網址帶版本號，會自動更新。
- 統計頁：點表格欄位標題可切換排序；可匯出「統計表」與「逐筆清單」兩種 CSV。
- 議題頁：可看到、移除、追加照片。

## v3.3 新增
- 補登、家代填寫、每筆紀錄都可勾選「這天沒有家代照片時，前台顯示平台菜色照片」。
- 平台菜單可一次同步一段期間（今天／近14天／近30天／本月／上個月／本學期，或自訂起訖），可中途停止。
- 查詢平台有逾時保護：查不到會顯示「查不到，可手動填寫」與重試鈕，不會一直停在查詢中。
- 紀錄查詢可用日曆選起訖日期；紀錄預設收合，點開才編輯。
- 補登與「家代與設定」各區塊可收合，並記住開合狀態；手機版統計與連結改為卡片顯示。

## v3.4 新增
- **平台資訊更完整**：每道菜的類別（主食／主菜／副菜／蔬菜／湯品）、每日熱量與六大類營養份量、每道菜的食材與產地（含認證標章）。週報新增「本週營養份量」表。
- **修正平台照片網址**（舊版存成平台內部路徑），已存的舊資料會自動轉換；平台「無照片」預設圖自動略過。
- **先用瀏覽器向平台查詢**（平台允許跨網域讀取），查不到才請 Apps Script 查。
- **顯示由幹部決定**：每天的平台菜單、平台照片各有「自動／顯示／不顯示」。自動＝依家代或補登時的勾選；顯示＝不論家代選擇都顯示（平台照片與家代實拍並列）。同步一段期間時也可一併設定。
- 家代頁、補登、每筆紀錄都可勾選「帶入平台菜單」「帶入平台照片」。
- 前台：家代照片標示「📷 家代現場實拍」（綠框），平台照片標示「平台・非家代拍攝」（藍框）。
- 填寫範本只有一個按鈕，會依是否帶入平台菜單自動選擇，再按一次是**取代**不是往下加。
- 家代連結：可用「輪值日期」找出當天試菜代表；每人可產生 QR 圖卡（【日期 試菜代表】班級 姓名），也能把當天全部合併成一張圖；新增「整批重設全部連結」（QR 一起更換）。
- 總覽頁「今日輪值」可一鍵產生今天的 QR 合併圖。

## 六、請留意
- 照片存在你的雲端硬碟「東門試菜照片」，為「知道連結者可檢視」；連結只存在私有試算表與後台，不會出現在公開資料，但**審核前的照片網址仍可被知道網址的人開啟**，請務必在審核時檢查人臉與名牌。退回／刪除會把照片丟垃圾桶。
- 個人連結與 QR Code 等同密碼。若把 QR 圖貼在群組相簿，群組裡的人都能用它在該代表的輪值日送出紀錄（仍需幹部審核）；建議定期「整批重設」。
- 名冊只匯入「年級、班級、家長姓名」，不含學生姓名。
- 同姓名的兩位家代會被視為同一人，請避免。
- 通關密語只給幹部，定期更換（Script 屬性 `KEY`）。
