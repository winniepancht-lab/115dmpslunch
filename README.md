# 東門國小家長會・營養午餐試菜紀錄

純靜態網站（HTML + JSON + 圖片），可直接用 GitHub Pages 發佈，不需要後端或資料庫。

## 發佈到 GitHub Pages
1. 在 GitHub 建立新 repository（例如 `dongmen-lunch`）。
2. 把本資料夾內**所有檔案**（含 `.nojekyll`、`data/`、`img/`）上傳到 repository 根目錄。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一兩分鐘後，網址為 `https://你的帳號.github.io/dongmen-lunch/`。

> 注意：公開 repository 的所有檔案與修改歷史都是公開的，**上傳前請確認內容與照片已審核**。
> 已刪除的照片仍可能留在歷史紀錄中。
> 本機直接雙擊 `index.html` 會因瀏覽器限制讀不到資料，請用 GitHub Pages 或 `python -m http.server` 預覽。

## 檔案結構
- `index.html`：網頁（一般不用改）
- `data/semesters.json`：學期清單，例如 `["115-1"]`；新學期就加一個，如 `["115-1","115-2"]`
- `data/115-1.json`：該學期資料
- `img/`：橫幅與試菜照片

## 每天新增一筆試菜紀錄
在 `data/115-1.json` 的 `days` 陣列新增：
```json
{
  "d": "2026-11-11",
  "reps": [
    {"c": "206班", "l": ["白飯：軟硬適中", "三杯雞：鹹度適當", "湯：偏鹹"]}
  ],
  "ph": ["img/20261111-1.jpg"],
  "n": [
    {"t": "追蹤中", "x": "兩位代表回報同一道菜有異味，待向營養師確認。"},
    {"t": "營養師回覆", "x": "營養師回覆內容……"}
  ]
}
```
- `c`：只寫班級（如 `206班`），不要寫家長姓名。
- `ph`：照片放進 `img/`，只拍餐點，壓縮到約 600px 寬。
- `n.t` 為「追蹤中」或「營養師回覆」時，日曆會自動顯示標籤；也可用其他標題，如「家長提問」。

## 新增家長反映與校方回覆
在同一個檔案的 `qa` 陣列新增：
```json
{"m": "11", "t": "11/12｜問題標題", "x": "家長反映了什麼，以及營養師或學校如何回覆。"}
```
`m` 是月份（兩位數），決定出現在哪個月份分頁。

## 新學期
複製 `data/115-1.json` 為 `data/115-2.json`，改 `id`、`name`、`months`（例如 `["02","03","04","05","06"]`），清空 `days` 與 `qa`，再把 `"115-2"` 加進 `data/semesters.json`。注意跨年月份的年份：`d` 一律寫完整日期（如 `2027-02-24`）。

## 公開前檢查
- 試菜代表只顯示班級，不顯示姓名；不要貼 LINE 對話原文與暱稱。
- 照片沒有人臉、名牌、班級座位。
- 營養師與學校的回覆已取得同意公開。
- 不放廠商名稱、未證實的傳言或個案資料。
