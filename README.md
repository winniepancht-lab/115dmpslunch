# 東門國小家長會・營養午餐試菜紀錄（Google 試算表版）

**一次設定，之後每天只需要用手機填表，不用重新佈版。**
資料存在 Google 試算表、照片自動存到 Google 雲端硬碟，網站每次開啟都會讀最新資料。

## 一、第一次設定（約 20 分鐘，只做一次）

### 1. 試算表
1. 開啟你原本的試算表，**先刪掉測試資料**（例如 11/12 的 102、509 兩列，前台會公開顯示）。
2. 第一個分頁改名為 `試菜`，標題列改成（最後多一欄「公開」）：
   `日期 | 班級 | 午餐菜色 | 家代意見反饋 | 照片連結 | 營養師回應 | 公開`
3. 匯入既有資料：檔案 → 匯入 → 上傳 `seed/試菜_匯入.csv` → 選「**在目前的工作表後面附加資料列**」。
4. 新增分頁，命名為 `反映`，標題列：`日期 | 標題 | 反映摘要 | 營養師回覆 | 狀態 | 公開`，同樣匯入 `seed/反映_匯入.csv`。
   （9 月以來的 15 則反映與回覆都在這裡。）

### 2. Apps Script（取代原本程式碼）
1. 擴充功能 → Apps Script → 把 `Google_Apps_Script.js` 全部貼上，儲存。
2. 專案設定（齒輪）→ 指令碼屬性 → 新增 `KEY`，值填幹部共用的**通關密語**。沒有它任何人都無法寫入。
3. 部署 → 管理部署作業 → 編輯 → 版本選「**新版本**」→ 部署（網址不會變）。
   第一次會要求授權（需要存取試算表與雲端硬碟，用來存照片），請同意。

### 3. 發布兩個分頁（給網站讀取）
檔案 → 共用 → 發布到網路 → 分別選 `試菜`、`反映` 分頁，格式選 **CSV**，各複製一個連結。

### 4. 設定網站
打開 `js/config.js`：`DATA_URL` 貼試菜分頁連結、`QA_URL` 貼反映分頁連結、`GAS_URL` 貼 Apps Script 網址。
然後把整個資料夾上傳到 GitHub Pages。**之後除非換網址，否則不用再碰這些檔案。**

## 二、每天怎麼更新
開啟 `你的網站/admin.html`（輸入一次通關密語，手機會記住）：
- **今日試菜**：選日期、班級、貼試菜文字、選照片 → 送出。照片會在手機端自動縮小、上傳到雲端硬碟，前台自動顯示。同天第二位代表再送一次即可。
- **新增反映事項**：有問題才填；回覆留空會顯示「追蹤中」。
- **補回覆**：營養師回覆後，在第 3 區選該則、貼上回覆即可，不用進試算表。
- 前台約 1–5 分鐘內更新（Google 發布 CSV 有快取）。

## 三、日常維護小技巧
- **不想公開某一列**：在試算表該列「公開」欄填 `否`，前台立刻（幾分鐘內）隱藏，也可事後刪除或修正文字。
- **手動貼照片**：照片連結欄可貼 Google 雲端硬碟分享連結（需設為「知道連結的人可檢視」）或網站內路徑（如 `img/xxx.jpg`），多張用逗號分隔。
- **學期、月份自動產生**：依日期判斷（8–1 月＝上學期、2–7 月＝下學期），新學期不用手動建立。

## 四、請留意
- **試算表發布後是公開的**：任何人都能下載 CSV，裡面的「班級」欄也看得到（前台只顯示年級）。不要在試算表放家長姓名、電話等資料。
- 照片檔案存在你的雲端硬碟「東門試菜照片」資料夾，並設為知道連結者可檢視；公開前請抽查有沒有人臉、名牌。
- 通關密語是唯一的防護，請只給幹部，並定期更換（改 Script 屬性 `KEY` 即可）。
- 前台頁尾保留一個小小的「家代填寫入口」連結；若不想公開，從 `index.html` 刪掉即可，直接用網址進入。
