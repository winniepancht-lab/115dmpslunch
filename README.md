# 東門國小營養午餐紀錄系統 (v3 全站升級包)

此更新包包含了前端網站完整升級所需的所有原始碼檔案。

## 最新升級重點 (v3)
1. **API 日期修復**：修正 `js/admin.js` 網址字串 `replace` 的順序，確保成功向國教署 API 抓取菜色。
2. **自動帶入菜色**：家代於 `admin.html` 切換日期時，將自動連線 API 並填入「今日菜色」。
3. **多圖上傳支援**：家代可一次選取多張「菜單圖片」與「試菜照片」，系統統一進行縮圖上傳。
4. **幹部隱藏面板**：於 `admin.html` 輸入超級密碼 (`superadmin123` 或含 `super`) 即可解鎖底部「幹部進階管理」專區，進行議題管理。
5. **程式碼整理**：將 CSS 獨立至 `css/style.css`，並明確劃分 `js/` 模組，提升維護性。
