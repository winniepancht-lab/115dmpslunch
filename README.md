# 東門國小家長會・營養午餐試菜紀錄（v2）

這包已經放入你的 `js/config.js`（網址都設定好了），**直接整包覆蓋上傳到 GitHub 即可，不用再貼任何網址**。
`seed/` 資料夾只在第一次匯入資料時使用，平常不用管。

## 這次更新要做的事（一次）
1. **Apps Script**：把 `Google_Apps_Script.js` 全部貼上取代 → 儲存 → 部署 → 管理部署作業 → 鉛筆圖示 → 版本選「新版本」→ 部署。
   網址與 KEY 都不用動；試算表缺少的欄位（`菜單圖片`、反映的 `照片連結`）和新的 `排班` 分頁會自動建立。
2. **上傳網站**：把整個資料夾內容覆蓋上傳到 GitHub（`css/`、`js/`、`index.html`、`week.html`、`admin.html` 都是新的）。
3. **不要把「排班」分頁發布到網路**（它不含姓名，但仍建議不公開）。

## 每天怎麼用（`你的網站/admin.html`）
- **今日試菜**：選日期 → 上方會顯示「今日輪值班級」（✓ 表示已回報，點一下自動填班級）→ 貼文字、選照片、可附菜單圖片。
  不知道怎麼寫時，按「插入範本」會帶入 白飯／主菜／副菜／青菜／湯／整體。
- **新增反映事項**：可附照片；回覆留空 = 前台顯示「追蹤中」。
- **補回覆**：營養師回覆後選該則貼上即可。
- **匯入輪值排班表**（幹部專用，換月份或有調整時做）：選輪值表 xlsx 與名冊 xlsx → 解析並匯入。
  檔案只在你的手機/電腦解析，只上傳「日期＋班級」，不會上傳任何姓名。

## 前台新功能
- 月份內以「週」為單位，**只展開最新一週**，其他週次收合（點開才載入，速度也更快）。
- 照片改為格狀縮圖，點開可放大、左右切換。
- 每週有「📄 查看本週週報」；也可直接開 `week.html`。週報自動依試算表產生，含統計、回饋關鍵字、反映與回覆、照片，可按「列印／存成 PDF」。
- 追蹤中（琥珀色 ⏳）、已回覆（綠色 ✅）、已說明（藍色 💡）。

## 維護小技巧
- 不想公開某一列：該列「公開」欄填 `否`，前台幾分鐘內隱藏。
- 手動貼照片：照片連結欄可貼 Google 雲端硬碟分享連結或 `img/xxx.jpg`，多張用逗號分隔。
- 學期、月份、週次都由日期自動產生，不用手動建立。

## 請留意
- 試算表發布後是公開的，「班級」欄任何人都能下載；不要放姓名、電話。
- 照片存在你的雲端硬碟「東門試菜照片」（知道連結者可檢視），公開前請抽查人臉、名牌。
- 通關密語是唯一的防護，只給幹部，並定期更換（改 Script 屬性 `KEY`）。
- 回饋關鍵字是程式依文字自動統計，僅供參考，可能有誤判。
